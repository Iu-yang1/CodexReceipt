Codex 桌面小票 · 工程与功能说明

便携版启动：export\Windows-x64\CodexReceipt.exe；开发版构建见“工程构建说明.txt”。
桌面只显示纸票，背景、打印机、按钮和状态栏均不显示；通知区域保留后台托盘图标。
普通票保持白色，使用与对话预览一致的 DotGothic16／VT323 字体与排版。
字体随程序保存到 fonts 目录；纸宽为 290 CSS 像素，按 Windows 缩放自动匹配物理尺寸。
每张纸票保留标题，小标题保持单行，上下边缘有 2 CSS 像素深的细锯齿。
纸票顶端增加居中的单色 Codex 图标和字标，采用小票店铺标志的黑底白字排版。
保留“账单”／“警告”标题，纸边加轻微内阴影；额度方格条下的说明文字已移除。
右键任意小票：打印音效、全部折叠、撕下全部小票、打印当前额度、分别打印黄色／红色／青色小票、退出。
右键“连续打印 10 张演示票”：复制最近的额度快照为演示样票，不发起 Codex 调用，不计作实际消费。
打印音效默认开启，修改后会保存偏好。
鼠标停在某张折叠票上：只展开这一张；移开即开始收拢。
最新小票打印完成后保留 5 秒；查看其他票或碰到窗口边界时优先收拢让位。
查看单张小票时，其他票立即收拢，展开高度受窗口剩余空间约束。
正在出票时先完成打印，随后折叠，避免两种动画冲突。
上半部保持平直，下端沿连续弧面卷起；纸面始终不透明，阴影集中在卷边。
完全折叠时只露出纸背与柔和折边，文字和 Logo 藏入折层；悬停展开后恢复阅读。
各张折叠厚度为稳定的 8–14 CSS 像素，横向错位不超过约 2 像素，折边弧度略有差异。
折叠内部没有锯齿；锯齿只保留在展开后的纸张实际上下边缘。
自动收拢逐张错开约 55 毫秒；出票压缩量不超过实际送纸长度，保留从邻近纸票开始的推挤效果。
选中纸票正文后按空格：添加浓黑手涂墨迹，边缘带不规则毛边、叠涂和飞白。
Codex 图标及字标带轻微斑驳油墨和磨损边缘，纸面仍保持干净。
按住左键快速向左拖动已打印的小票：撕下这张及其之前的所有小票，较新的票保留。
向左移动至少 96 CSS 像素、平均速度至少 0.65 像素/毫秒、总时长不超过 340 毫秒才触发；慢速拖动保留文字选择。
撕票用 520 毫秒的断开、向左抽离动画；打印过程中不撕票，避免破坏连续送纸。
Ctrl+Z 撤销上一次涂黑。标记随本次会话的票据保留，折叠、展开不会丢失。
纸票之外的区域不占用桌面点击。
撕下全部小票后，程序继续等待下一笔用量，下一张从新纸带开始。

数据来源
1. 使用本机已登录的 Codex app-server，只调用初始化和 account/rateLimits/read。
   每 60 秒更新账户额度，不创建任务、不发送提示词。
2. 每 2 秒读取 ~/.codex/sessions 中最近活跃会话新增的事件元数据。
   按任务轮次汇总输入与输出 Token，完成或中止后出票。
   启动时已在运行的轮次只统计启动后的增量，并在票上标明。
3. 缓存 Token 已包含在输入 Token 中，不重复相加；推理 Token 不额外加到输出上。
4. 账户接口不可用时使用日志中最近的额度快照，票上保留额度采样时间。
   本地未同步的其他设备/云端任务，无法获得其逐轮 Token 账单。
5. ChatGPT/Codex 订阅额度不等于 API 余额，不推算美元花费。
   额度百分比与 Token 没有固定换算关系，账户额度的更新也可能有延迟。

纸票
白票：用量账单；启动或手动请求时打印额度快照，并展示“最近一次 Token 用量”。
最近调用来自真实日志记录，仅供快照展示，不重复计为新消费。
黄票：剩余额度大于 0% 且小于等于 10%，每次任务结束后跟随账单追加一张；同额度状态下也会重复提醒。
红票：偏橙的朱红色纸张配深色文字；额度用尽，显示重置时间与打印时距重置的静态时间。
黄红票独立打印，跟在账单之后；手动快照不反复追加同状态黄票，红票保留同额度周期的重复抑制。
青票：收到新额度周期的实际数据时，打印“额度已重置”，显示当前剩余百分比、方格条、重置时间和下次重置时间。
启动时建立额度基线；时钟到点不会单独触发青票，须由新的账户或日志采样确认，同周期只通知一次。任务完成仍不触发青票。
所有票面均不显示“演示”及相关提示，手动样票的内部标记仍与真实账单区分。
送纸达到窗口上边界即推动旧票卷起，不再按票数触发。
所有票据的时间均为静态快照，不实时倒计时。

试运行范围
不设置开机启动，不修改 Codex 配置，不读取或保存 API Key、提示词或回答内容。
WebView2 缓存和偏好位于 %LOCALAPPDATA%\CodexReceipt。普通运行不保存用量调试文件或账单截图。
历史账单仅保存在本次运行的内存中，退出后不会保留。
编译源码需保留工程目录及上一层模板；便携版只需 EXE，自带 .NET，使用目标电脑的 WebView2。

markerCheck：实际 WebView 中选中文字、空格涂黑、卷起再展开及 Ctrl+Z 撤销的检查结果。
