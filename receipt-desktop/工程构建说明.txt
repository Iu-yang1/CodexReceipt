Codex 小票 · 完整源码工程

目录关系
api-receipt.html 位于 receipt-desktop 文件夹的上一层，是生成桌面界面的模板。
请保留压缩包内的这层目录关系。
receipt-desktop 包含 C# 源码、项目文件、前端脚本、字体、图形、许可、测试和构建脚本。
receipt-desktop/export/Windows-x64 内附可直接运行的便携版 EXE 及使用说明。

构建环境
Windows x64，.NET 10 SDK、Python 3.10 或更新版本、PowerShell。
运行 JavaScript 检查还需要 Node.js 18 或更新版本。
首次还原依赖需要连接 NuGet；字体和图形已包含，不需要再下载。

在 receipt-desktop 目录中执行
构建开发版：
  ./build.ps1 -Action Build
运行全部检查：
  ./build.ps1 -Action Test
生成独立 EXE：
  ./build.ps1 -Action Publish

也可以指定 Python 和 Node 的路径：
  ./build.ps1 -Action Test -Python "C:/Tools/Python/python.exe" -Node "C:/Tools/Node/node.exe"

产物
开发版：bin/Development/CodexReceipt.exe
便携版：export/Windows-x64/CodexReceipt.exe
便携版内置 .NET 运行库、字体和界面资源，仍使用目标电脑的 WebView2 Runtime。
构建脚本将依赖缓存保存在本工程 .packages 目录，不把缓存包含进导出 EXE。
第三方许可位于 licenses 和 fonts 目录，并嵌入便携版的 UI 资源包。

实现入口
Program.cs：窗口生命周期、打印队列、账户状态、额度警告。
ReceiptTrayUi.cs：后台托盘图标和菜单。
AccountClient.cs / CodexLocator.cs：发现本机 Codex 并连接账户只读接口。
UsageMonitor.cs / QuotaResetTracker.cs：任务用量和额度周期检测。
AppPaths.cs：资源解包、用户目录和偏好设置。
build-ui.py：把模板及桌面脚本合成为 index.html。
paper-folds.js / paper-interactions.js：卷曲、悬停和堆叠。
paper-marker.js / paper-tear.js：马克笔遮盖和左拖撕票。
package-ui.py：只将明确列出的公共资源打成 ui.zip。
SelfTest.cs / test-*.cjs：使用合成数据验证业务和交互逻辑。

数据隔离
本源码包不包含个人使用量、账单截图、账号凭据、浏览器缓存或调试结果。
普通运行的数据目录为 %LOCALAPPDATA%/CodexReceipt，不写入工程或 EXE 所在目录。
测试结果写入 .verification，已列入 .gitignore。
不要把个人 .codex 目录、auth.json 或运行时缓存添加到源码分发包。
原有 使用说明.txt 包含设计阶段说明；当前便携版操作以 export/Windows-x64/使用说明.txt 为准。
