# CodexReceipt
Codex 小票 

开始使用
1. 将 CodexReceipt.exe 复制到目标电脑，双击启动。
2. 目标电脑需要已安装并登录 Codex 桌面版或 Codex CLI。
3. 小票会自动检测常见的 Codex 安装位置，连接本机登录，读取订阅额度及本机任务用量。
4. 未找到 Codex 时，右键任务栏通知区域的小票图标，选择“选择 Codex 程序…”，选中命令行程序 codex.exe，再重新连接。

后台图标
启动后保留一个小票托盘图标；Windows 可能将其收在任务栏的展开区域。
双击图标显示小票；右键可显示／隐藏、重新连接、切换音效、打印普通和特殊小票、退出。
隐藏小票后仍在后台运行；“退出”会结束后台程序。

数据与隐私
导出文件不包含制作者的账号、用量、账单、截图、API Key、登录信息或浏览器缓存。
复制 EXE 不会复制任何已有个人数据。
运行后使用目标电脑当前用户的 Codex 登录及本地记录，不要求把登录文件交给本程序。
只通过 Codex 本机账户接口读取账户状态与额度，不发送提示词，不创建任务，不消耗推理额度。
任务用量来自 CODEX_HOME/sessions，未设置 CODEX_HOME 时使用当前用户的 .codex/sessions。
普通运行不保存用量调试文件和账单截图；账单历史只在内存中保留。
界面缓存、音效偏好和手动选择的 Codex 路径保存在 %LOCALAPPDATA%\CodexReceipt，和 EXE 分开。
内置资源及第三方许可展开在上述目录的 ui 子目录，不随分享 EXE 带出本机缓存。

纸票操作
白票显示任务用量和额度快照；所有打印时间保持静态。
0% < 剩余额度 <= 10% 时，每次任务结束后追加黄票；用尽时追加红票。
实际检测到新额度周期时追加青票；也可在右键菜单分别手动打印黄、红、青票。
鼠标悬停折叠票可展开；移开后收起，新票保留约 5 秒。
选中文字后按空格添加墨迹，Ctrl+Z 撤销。
按住左键快速向左拖动已打印的票，撕下这张及更旧的小票。
打印音效默认开启，可从托盘或票面右键菜单关闭，设置会记住。
